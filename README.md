# Suhail Labs — Final Website v2

Suhail Labs is a focused developer portfolio and project platform for **web applications, software systems, database-driven tools, AI-ready assistants, admin/analytics interfaces, and interactive 3D web experiences**.

## Public website

- `index.html` — main portfolio
- `project.html?id=001` — reusable project detail template
- `links.html` — official profile/link hub
- `work-with-me.html` — client workflow and project brief
- `404.html` — fallback page

## Creator Studio

- `admin.html` — local-first Creator Studio

Creator Studio can manage the public profile, project metadata, platform links and export `site-data.js`. Its local passcode is only a browser-workspace lock; it is **not server-side authentication**.

## Public assistant

The main website includes **Suhail Labs Assistant**, a zero-cost local portfolio knowledge assistant. It answers from the published project/profile data in the browser and does not send visitor questions to an external AI provider.

## Current portfolio

### Project 001 — Smart Ordering & Kitchen Operations Dashboard
Business-software workflow demo with customer ordering, cart logic, checkout simulation, operations states and live metrics.

### Project 002 — Interactive 3D Network Operations Lab
Browser-based interactive technology visualization with topology, animated traffic, inspection and monitoring-state simulation.

### Project 003 — Suhail Medical Dictionary
A larger public web/PWA project represented by its real GitHub repository. The portfolio links to the repository and source ZIP.

## Free deployment model

The site is static and deployable on GitHub Pages without a paid server, database or AI API.

## Security

Never publish passwords, API keys, private client data, production database credentials or secrets in this repository.
