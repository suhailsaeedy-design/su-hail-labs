# Security Policy

Suhail Labs is a public portfolio repository. Treat all committed content as public.

## Never commit
- Passwords
- API keys or tokens
- Recovery codes
- Private client data
- Private database backups
- Identity documents
- Secrets copied from `.env` files

## Reporting a problem
If a public project contains a security issue, document the affected project and the behavior without publishing private credentials or exploit secrets.

## Creator Studio note
The bundled Creator Studio is local-first. Its browser passcode is a local convenience lock, not server-side authentication and not a secure cloud admin system.
