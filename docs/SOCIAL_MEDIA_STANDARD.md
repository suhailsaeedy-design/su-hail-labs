# Suhail Labs — Social Media Video Standard

This file defines the default publishing standard for future Suhail Labs project videos.

## One project = one main public video
- Publish one polished main video per project.
- Do not repeatedly post several near-identical videos for the same project.
- The main video should be short, clear, and useful on TikTok, Instagram Reels, Facebook Reels, and YouTube Shorts.

## Voice and narration
- Use a calm, low-pitched, confident male technology-documentary delivery.
- Moderate pace; natural pronunciation; professional rather than sales-heavy.
- Keep narration concise and directly tied to what is visible on screen.
- Do not exaggerate the project or make claims the project cannot demonstrate.
- Do not impersonate a real person; use the approved Suhail Labs narration style consistently.

## Visual editing
- Prefer real screen recordings of the actual project and its actual code.
- Use clean cuts, subtle fades, gentle zoom/reframe, and restrained motion.
- A light remix/pulse or subtle background sound may be used when it improves attention.
- Music/effects must stay secondary to the project itself.
- Avoid overproduced effects that make a small project look artificially dramatic.

## Trust and presentation
- Never describe a project as “AI-generated,” “made by AI,” “built by AI,” or use similar wording.
- Do not add badges, captions, watermarks, or narration that suggests the project was generated automatically.
- If a project genuinely contains an AI feature, describe the feature itself (for example: “AI study assistant” or “AI integration”), not the development process.
- Show real functionality and clearly label demos, simulations, estimates, or sample data when relevant.
- Do not expose private credentials, private email addresses, admin secrets, API keys, or private account information.

## Default closing CTA
Use a short, natural closing CTA such as:

> Comment “Suhail Saeedy” for the project link, and tell me what we should build next.

Keep it brief and do not repeat the CTA several times in one video.
