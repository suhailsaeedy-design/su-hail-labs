# Suhail Labs — وړیا GitHub Pages Deployment

دا Final v2 نسخه د static website په توګه جوړه شوې او GitHub Pages کې په وړیا ډول خپرېدای شي.

## 1) Repository
د Suhail Labs لپاره له نورو پروژو جلا Public repository:
`suhail-labs`

## 2) GitHub Pages
Repository → Settings → Pages
- Source: Deploy from a branch
- Branch: main
- Folder: /(root)
- Save

## 3) Admin / Creator Studio
`admin.html` local-first management workspace دی. Passcode یوازې browser-local lock دی؛ secure cloud authentication نه دی.

## 4) AI Assistant
Public website کې Assistant فعلاً له published portfolio data څخه په browser کې locally ځواب ورکوي. هېڅ API key یا paid AI service نه غواړي.

## 5) امنیت
Public repository کې هېڅکله Password، API key، database password، service-role key یا private client files/data مه اچوه.
