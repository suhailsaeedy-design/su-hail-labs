CLIENT WORKFLOW

A simple four-stage process.

Each stage reduces ambiguity before more time is spent on implementation.

01

Brief

Goal, users, required features, deadline, target devices and examples.

02

Specification

The rough idea is converted into a professional feature list, page flow and delivery plan.

03

Build & review

The project is implemented in checkpoints so important changes are caught early.

04

Handoff

Final files, documentation and agreed deployment or publishing instructions are delivered.

PROJECT BRIEF

Send these details first.

Copy this checklist into the platform where you contact me. Clear answers make estimation and planning much easier.

  1. Project goal: What should the finished project achieve?
  2. Users: Who will use it?
  3. Core features: What must it do?
  4. Platforms: Web, mobile browser, desktop, or another target?
  5. Design direction: Share references you like, if available.
  6. Content: What text, images, products or data already exist?
  7. Deadline: Is there a target date?
  8. Delivery: Source files, live deployment, documentation, or all three?
